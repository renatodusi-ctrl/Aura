# Product

## Positioning

AURA is a local personal cockpit, not a cloud dashboard.

## Core Jobs

- Start a voice session quickly.
- Keep local memory and tasks.
- Ask for confirmation before sensitive actions.
- Offer daily routine help while open.
- Stay useful without an OpenAI key.

## Non-Goals for MVP

- Background daemon.
- Always-on listening.
- Cloud sync.
- Unprompted screen capture.
